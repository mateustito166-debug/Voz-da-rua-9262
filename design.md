# Voz da Rua — Design

Static, pixel-faithful replica of the "Prefeitura" profile screen (web). No navigation, no submit, no modals.

## Colors
- Sidebar background: `#173772`
- Sidebar right accent stripe / active pills: `#619AF7`
- Sub-menu guide line: `#4F7FD0`
- Sidebar dividers: `rgba(255,255,255,0.45)`
- Title / dashed line: `#173772` / `#5A73A3`
- Danger button: `#F42725` · Primary button: `#5580F7`
- Input bg `#F5F5F5`, input text `#AEAEAE`, labels `#1F1F1F`

## Typography
- Inter (sidebar, page title — 800 weight, tight tracking)
- Poppins (section title, labels, inputs, buttons)

## Layout
- Sidebar 288px + 16px light-blue stripe, full viewport height; "Sair" pinned to bottom.
- Content: header with title left and buttons right, dashed divider, 2-column form grid (384px inputs, 43px gap, 116px row pitch).
